## 2026-06-29 - Accessible Icon-Only Toggle Buttons
**Learning:** Non-native icon-only toggle buttons (like password visibility toggles using <i> tags) are completely invisible to screen readers and inaccessible via keyboard navigation. When making them accessible, it's critical to not only add `role="button"`, `tabindex="0"`, and `keydown` event listeners for 'Enter'/'Space', but also to dynamically update the `aria-label` attribute alongside the visual state (e.g., from 'Tampilkan password' to 'Sembunyikan password') so screen reader users get accurate feedback of the current state.
**Action:** Whenever implementing custom non-native toggle elements, always implement a shared handler function that updates both the visual classes and the `aria-label` attribute simultaneously, and ensure the handler is bound to both click and keyboard events using `.call(this)` to preserve execution context.
