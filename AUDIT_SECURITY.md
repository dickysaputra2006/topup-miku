# Audit Keamanan Backend — `topup-miku`

**Tanggal Audit:** 15 November 2026  
**Cakupan:** Seluruh kode di folder `/backend` (`server.js` [4.422 baris], `cron_job_script.js`, `seed_local_dummy.js`, `benchmark_roles_update.js`, `utils/cronUtils.js`, `utils/mailer.js`, `utils/validators/*`, `package.json`, `.env.example`), disertai peninjauan skema (`setup_db.sql`, `migrations/*`, `.gitignore`).  
**Standar Acuan:** `.agent/skills/miku-store-pro-standar.md` (Bagian 5: Security & Bagian 10: Larangan Mutlak).  
**Catatan Batasan (Read-Only):** Tidak ada file kode atau konfigurasi yang diubah selama audit ini. Nilai aktual `backend/.env`, konfigurasi web server/reverse proxy (Nginx/Cloudflare), status database runtime, dan kode `frontend/` tidak diperiksa langsung (**perlu verifikasi** terpisah).

---

## Ringkasan Eksekutif

Secara fondasi, sejumlah guard penting sudah ada di kode: penggunaan query SQL berparameter (`$1, $2`), `SELECT ... FOR UPDATE` untuk pemotongan saldo order dan persetujuan deposit, constraint `CHECK (balance >= 0)` serta partial unique index refund/deposit (`migrations/007_concurrency_and_balance_guards.sql`), validasi harga di server dari DB + cek real-time ke Foxy, serta helper sanitasi log (`logSafeError`, `safeAxiosError`).

Namun ditemukan beberapa celah **Kritis** dan **Tinggi** yang berdampak langsung terhadap keamanan finansial, integritas transaksi, dan kepatuhan terhadap `miku-store-pro-standar.md`:

- **Total Temuan:** **29** (**6 Kritis**, **11 Tinggi**, **8 Sedang**, **4 Rendah**)
- **Dependensi (`npm audit`):** **9 kerentanan** (**2 Critical**, **4 High**, **3 Moderate**) pada dependensi langsung dan transitif (`proxy-addr`, `form-data`, `axios`, `jws`, `ip-address`, `body-parser`, `follow-redirects`, `qs`).

## 5 Prioritas Perbaikan Pertama

1. **Perbaiki bug race condition kompensasi & double-refund di Phase 2 Order (`SEC-002`) dan celah price guard promo (`SEC-003`)**  
   *Alasan:* Berdampak langsung pada kerugian uang nyata secara instan — baik pesanan berhasil yang ikut ter-refund penuh (`lockedTxRows.length === 0` di `server.js:3791, 4228`) maupun produk yang terjual hingga Rp 1 di bawah modal Foxy setelah potongan promo (`server.js:3637 vs 3698`).

2. **Kunci & keraskan keamanan `POST /api/foxy/callback` (`SEC-001`)**  
   *Alasan:* Webhook pembayaran/fulfillment saat ini berstatus *fail-open* jika `FOXY_CALLBACK_SECRET` kosong, menerima token lewat URL query, tanpa verifikasi tanda tangan HMAC maupun validasi nominal, serta menerima `sn`/`message` mentah dari `req.body`. Harus fail-closed, ber-HMAC, dan tidak membaca field tak terverifikasi dari `req.body`.

3. **Amankan API Key H2H (hash di DB, tampilkan sekali, panjang >= 32 byte), perbaikan CIDR/SSRF webhook H2H (`SEC-004`, `SEC-007`, `SEC-008`)**  
   *Alasan:* API key plaintext di DB dan bisa diambil ulang via `GET /api/user/apikey` membuka risiko pengurasan saldo penuh, sementara `protectH2HIp` gagal memvalidasi CIDR, absen pada `/h2h/profile/callback`, dan URL callback H2H belum terlindungi dari SSRF DNS rebinding/redirect maupun dilengkapi HMAC signature.

4. **Tambahkan `idempotency_key`/`ref_id` unik untuk Order & Deposit (`SEC-009`) serta perbaikan pool DB / timeout eksternal (`SEC-013`)**  
   *Alasan:* Mencegah pemotongan saldo ganda akibat network retry serta mencegah habisnya koneksi pool PostgreSQL (`DoS` seluruh website) ketika API PGSCODE/Mobapay/Foxy/Brevo mengalami gangguan atau timeout.

5. **Wajibkan 2FA TOTP Admin + Audit Log (`SEC-005`, `SEC-010`) dan tambal kerentanan kritis/tinggi dependensi `npm audit` serta global error/CSP/TLS DB (`SEC-006`, `SEC-015`, `SEC-016`)**  
   *Alasan:* Melindungi titik kendali tertinggi aplikasi (panel admin dan IP/rate-limit middleware yang terimbas CVE kritis `proxy-addr` serta CVE tinggi `axios`/`jws`), menegakkan jejak audit setiap perubahan saldo/margin, serta menghentikan potensi kebocoran stack trace maupun sertifikat DB yang tak terverifikasi.
